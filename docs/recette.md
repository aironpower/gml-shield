# Tableau de recette GML-SHIELD

Chaque exigence de l'énoncé est reliée à l'endroit du code qui la met en œuvre et à sa preuve : un test automatisé (exécuté à chaque pull request par la CI) et, quand c'est pertinent, une vérification visible dans l'application déployée (https://gml-shield.onrender.com).

Les chemins sont relatifs à `src/` (code) et `tests/` (tests). Les fonctions sont citées par leur nom plutôt que par un numéro de ligne, qui change à chaque modification.
